# Modern React with Testing - Course Materials

## Course Overview

**Duration:** 2 Days (16 hours total)  
**Participants:** 20+ developers  
**Industry Focus:** Banking/Financial Applications  
**Emphasis:** Engineering practices, team collaboration, design trade-offs, and testing strategies

### Core Values
- 🎯 **Fun** - Engaging, hands-on learning experience
- 🤝 **Collaborative** - Team-based exercises and pair programming
- 💡 **Sharing** - Knowledge exchange and best practices
- ✅ **Usefulness over Completeness** - Practical skills over theoretical perfection
- 🎓 **Professionalism** - Industry-standard practices
- ✔️ **Correctness** - Type safety, testing, and quality assurance

---

## Target Audience & Prerequisites

### Who Should Attend
- **Junior to Mid-level Developers:** Upgrading from legacy React (Class Components/Redux) to Modern React (Hooks/Next.js)
- **Frontend Engineers:** Building confidence in delivering enterprise-grade applications with automated testing
- **Full-stack Developers:** Creating robust UIs with TypeScript and CI/CD integration

### Prerequisites
- ✅ **Fundamental JavaScript (ES6+):** Arrow Functions, Destructuring, Spread Operators, Promises/Async-Await
- ✅ **Node.js Environment:** Node.js v20.x+ (LTS) installed
- ✅ **Editor:** Visual Studio Code with recommended extensions (Tailwind CSS, ES7+ React Snippets)
- ✅ **Basic Git knowledge:** Clone, commit, push/pull

## Setup Instructions

### 1. Clone the Repository
```bash
git clone <repository-url>
cd example-modern-react-testing
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Verify Setup
```bash
npm run verify-setup
```

### 4. Start Development Server
```bash
npm run dev
```

### 5. Run Tests
```bash
npm test
```

## Teaching Philosophy

This course emphasizes:

1. **Engineering Practices over Syntax Memorization**
   - Focus on "why" and "when" rather than just "how"
   - Real-world scenarios from banking/financial industry
   - Team collaboration patterns

2. **Design Trade-offs**
   - Performance vs. Developer Experience
   - Type safety vs. Flexibility
   - Testing coverage vs. Development speed
   - Server vs. Client rendering decisions

3. **Testing Strategy**
   - Testing Trophy approach (Integration > Unit > E2E)
   - Testing user behavior, not implementation details
   - Balancing test coverage with maintainability
   - Cost-benefit analysis of different testing layers

4. **Hands-on Learning**
   - 60% practical exercises, 40% theory
   - Pair programming sessions
   - Code reviews and discussions
   - Real banking/financial use cases
